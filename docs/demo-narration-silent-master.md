# Demo narration

Read conversationally and pause as each visible action completes.
This version follows only the active demo flow.

## 0:00–0:18

3D scenes contain many objects, materials, and revisions. Asking an AI
to hunt through pixels is unreliable, but giving it invisible write
access is worse. GoSX 3D Studio gives the browser precise scene access
while keeping the final decision visible.

## 0:18–0:36

This page exposes four WebMCP tools: inspect, find, focus, and stage.
Together they let the browser understand and prepare work inside the
real Studio. There is deliberately no commit tool.

## 0:36–0:58

First, Chrome inspects the current scene and revision. Then it searches
the structured scene data for Board and resolves the stable object ID
`board`. Notice that the Coral Piece is still selected—the search has
not imitated a user click.

## 0:58–1:15

Focus now brings Board into the visible hierarchy and Inspector. Stage
checks two requested edits against the current revision and opens a
reversible preview in the same workspace.

## 1:15–1:44

The review shows the exact result: Board becomes Launch Board, and
Carved Wood becomes Brushed Steel. The live viewport renders that
proposal, but the badge still says not committed and the canonical
revision has not moved. I can orbit the scene and inspect the material
before deciding.

## 1:44–2:02

The browser has prepared the precise edit, but Apply remains a normal,
human-facing Studio control. It names the complete scope—two exact
edits—so the decision is clear before anything becomes permanent.

## 2:02–2:16

One approval commits both edits together and advances the scene once.
The persistent result and activity history distinguish who proposed the
work from who approved it. That is GoSX 3D Studio: agent precision with
human authorship.
